# ⚔️ Легендарное оружие (почти)

{% hint style="info" %}
Для отображения моделей необходим **ресурспак сервера**. Без него оружие выглядит как обычный незеритовый меч.
{% endhint %}

***

### 🔨 Как получить

1. Возьми **незеритовый меч**
2. Положи его в **наковальню**
3. Впиши точное **название** клинка в поле переименования
4. Забери меч — внешний вид сменится на выбранный

{% hint style="warning" %}
Название должно совпадать **точь-в-точь** — с заглавными буквами и пробелами, как в таблице ниже.
{% endhint %}

***

### ℹ️ Прочее

* Урон и характеристики — **как у незеритового меча**, отличие только визуальное
* Скин сохраняется на предмете: меч можно чинить и зачаровывать как обычно
* Ошибся в названии — просто переименуй меч ещё раз

{% hint style="info" %}
Модель отображается сразу после того, как заберёшь меч из наковальни.
{% endhint %}
